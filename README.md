# Customer Churn Analysis Project

## Project Objective

This project focuses on performing data audit, exploratory data analysis (EDA), and business understanding for customer churn prediction.

The analysis includes:

- dataset inspection,
- missing value analysis,
- duplicate analysis,
- join integrity checks,
- date consistency checks,
- churn behavior analysis,
- business-driven churn hypotheses.

## Repository Contents

- `eda_audit.ipynb`
- `data_quality_report.md`
- `business_memo.md`
- `requirements.txt`

## Key Insights

- Low purchase frequency is strongly associated with churn.
- Reduced session activity indicates declining engagement.
- High support-ticket activity may contribute to churn risk.
- Behavioral inactivity patterns are significant churn indicators.
